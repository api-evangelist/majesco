# Majesco GraphQL API

Majesco provides cloud insurance software. The API covers policy administration, billing, claims, underwriting, agency management, product configuration, and analytics for life, annuity, P&C, and group insurance lines.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Majesco REST API
**Documentation:** https://www.majesco.com/
